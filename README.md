# ヴァインランド 登場人物相関図

トマス・ピンチョン『ヴァインランド』の登場人物相関図です。

## GitHub Pagesで公開する方法

1. このフォルダの `index.html` をリポジトリ直下に置く
2. GitHub の **Settings → Pages** を開く
3. **Build and deployment** の Source を **Deploy from a branch** にする
4. Branch を `main`、Folder を `/(root)` にして保存する

相関図データは `index.html` 内に埋め込まれているため、追加ファイルは不要です。
